Web ESP Tool help




What it does


Flash, read, erase and merge firmware images, and inspect ESP-IDF NVS and LittleFS partitions through the ROM serial bootloader.






NVS explorer


Open the NVS tab, connect in download mode and click Extract NVS. The tool locates NVS partitions using the ESP-IDF partition table (usually at 0x8000), then decodes active entries locally.






LittleFS explorer


Connect an ESP in download mode, open LittleFS, and select Extract LittleFS. Files are reconstructed from the flash image without writing to the device. Expand folders to download individual files or choose Download ZIP for a complete archive.
