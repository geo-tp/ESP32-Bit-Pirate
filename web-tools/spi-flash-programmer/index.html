Web SPI Flash Programmer help




What it does


Read, erase, write and verify SPI NOR flash chips using a serprog-compatible adapter from the browser.






Adapter


    

  • Use hardware running a serprog-compatible firmware.
    • 

  • Connect CS, SCK, MOSI, MISO, GND and the correct flash supply voltage.
    • 

  • Use short wiring and a conservative SPI frequency when reading unknown boards in-circuit.
    •

  1. Power the flash chip safely before connecting.
