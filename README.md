## Flash from your browser

Each download is a complete merged firmware image containing the
bootloader, partition table and application firmware.

1. Download the firmware matching your board.
2. Open the [ESP Tool](https://geo-tp.github.io/ESP32-Bit-Pirate/web-tools/esp-tool/).
3. Connect the board through Web Serial.
4. Drag and drop the downloaded `.bin` file into the tool.
5. Start flashing.

No separate bootloader, partition file or offset configuration is required.
